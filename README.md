# Overview

The **Scenario Simulator** widget lists the scenarios available in your FortiSOAR&trade; environment and lets you run or reset a simulation without leaving the page you are working on. The widget opens as a half-width drawer on the *Scenario* page.

For each scenario, the widget displays its icon, title, tags, and description, along with a **Run Scenario** button for scenarios that have not been run, or a **Reset Scenario** button for scenarios that have already created demo records.

> [!Note]
>
> This widget is part of the **SOC Simulator** solution pack - `v1.1.0` and later - and is installed with it. The widget reads records from the Scenario module and triggers the Run Scenario and Reset Scenario playbooks, all of which the solution pack provides. Therefore, the widget requires the SOC Simulator solution pack to function.
> 

For information, see the section [**Using the Scenario Simulator widget**](https://github.com/fortinet-fortisoar/solution-pack-soc-simulator/blob/release/1.1.0/docs/usage.md#using-the-scenario-simulator-widget) in SOC Simulator solution pack documentation.
